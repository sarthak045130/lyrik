# Contributing

Thanks for helping improve Lyrik. For substantial changes, open an issue first so the approach can be discussed before implementation.

## Local setup

1. Install Node.js.
2. Run `npm install` in the repository root.
3. Run `npm start` to launch the app.
4. Use `npm run dist:mac` or `npm run dist:win` to build an installer for your platform.

Keep pull requests focused, describe the behavior change, and include the platform and player you used to verify it. Do not commit generated installers, `node_modules`, private audio, or credentials.
